Forward Deployed AI Engineer building production voice and chat agents with guardrails and eval loops.

## Featured: No Funny Business

The unbribable AI clerk for PayPal merchants. House rules run in code, not just in the prompt: verified payees, a kill switch, a signed receipt trail, and a red-team scorecard.

This is my [PayPal AI Hackathon 2026](https://paypalaihackathon.devpost.com/) submission.

[Live demo](https://merchant-desk-demo.onrender.com) · [Devpost](https://devpost.com/software/no-funny-business) · [Demo video](https://youtu.be/vMarccmj97A) · [GitHub](https://github.com/Sonteru4/no-funny-business)

The public demo uses mock PayPal. The policy engine is real.
