# 🎮 Tic-Tac-Toe Game

A beautiful, interactive Tic-Tac-Toe game built with vanilla HTML, CSS, and JavaScript.

## Features

- ✨ Modern, responsive design
- 🎯 Smooth animations and hover effects
- 🏆 Win detection and highlighting
- 🔄 Reset functionality
- 📱 Mobile-friendly interface

## How to Play

1. Visit `/tic-tac-toe/` on this GitHub Pages site
2. Click any empty cell to make your move
3. Players alternate between X and O
4. First to get 3 in a row wins!
5. Click "New Game" to reset

## Game Rules

- **X** always goes first
- Players take turns clicking empty cells
- Win by getting 3 in a row (horizontal, vertical, or diagonal)
- Game ends in a draw if all 9 cells are filled

## Technical Details

- **Frontend**: Pure HTML/CSS/JavaScript (no frameworks)
- **Styling**: Modern CSS with gradients and animations
- **Responsive**: Works on desktop, tablet, and mobile
- **Accessibility**: Keyboard navigation support
